1 — Main Loop loop()

The M7 core runs a non-blocking cooperative loop. Each iteration reads the current timestamp (millis()) and dispatches work to timed sub-tasks. The loop never calls delay() — all tasks are guarded by elapsed-time checks.

2 — Nicla Sensor Update niclaUpdate() — runs every 200 ms

Polls the Nicla Sense ME over BLE, applies outlier rejection, derives yaw from the orientation quaternion, and maintains a relative barometric altitude reference.

flowchart TD N1([niclaUpdate]) --> N2["BHY2Host.update()\n(processes pending BLE notifications)"] N2 --> N3["Read nicla_temp.value()\nRead nicla_barometer.value() ÷ 100 → hPa"] N3 --> N4{"T2 in −50 … 85 °C\nP2 in 300 … 1100 hPa?"} N4 -- pass --> N5["Update g_packet.primary\ntemperature2 / pressure2"] N4 -- reject --> N6["Discard (corrupt BLE packet)"] N5 --> N7["Quaternion → yaw_deg\natan2(2·(w·z + x·y), 1 − 2·(y²+z²))"] N6 --> N7 N7 --> N8{"!alt_init &&\npressure2 > 0?"} N8 -- yes --> N9["alt = Altitude(T2, 0, P2)\nalt_init = true\n(sets reference sea-level pressure)"] N8 -- no --> N10 N9 --> N10{"alt_init?"} N10 -- yes --> N11["nicla_altitude = alt.get_alt(T2, P2)"] N10 -- no --> NEND N11 --> NEND([return])

3 — Navigation State Machine navigationUpdate() — runs every loop

Advances the flight state and controls the two parafoil brake servos. State transitions are one-way and altitude-triggered. Checkpoint navigation is active only during descent with a valid GPS fix.

5 — Flight State Transitions

States are stored in g_packet.state and are strictly one-way.
