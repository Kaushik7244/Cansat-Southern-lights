Telemetry Packet Structure (TxPacket)

TierField groupFieldsTransport
Header Frame 0xAA 0x55 sync, LEN, CRC16 both radios
Metadata sequence, timestamp_ms, boot_epoch, state, m4_errors, m7_errors, flags both radios
Tier 1 Primary sensors temperature, pressure, humidity, altitude_baro (BME688 M4) + temperature2, pressure2 (Nicla) LoRa + APC220
Tier 2 GPS / secondary latitude, longitude, altitude_gps, speed_ms, heading, gps_satellites, gps_fix LoRa + APC220
Tier 3 Full sensor detail gas resistance, raw IMU, extended Nicla data SD card only — never transmitted
LoRa TX status: M7 Vision Shield LoRa AT TX commands are unsupported — LoRa TX in the M7 flight build is currently disabled. Active LoRa downlink is M4 RFM95W (SPI) → MKR WAN 1310 ground station.
